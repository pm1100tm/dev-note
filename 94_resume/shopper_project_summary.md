# 쇼퍼하우스 프로젝트 전체 요약

> **프로젝트 기간**: 2025.09 ~ 2025.12  
> **역할**: Backend Engineer  
> **프로젝트 구성**: ShopperHousePy (API 서버), ShopperHouseDataPy (데이터 처리)

---

## 📋 프로젝트 개요

쇼퍼하우스는 AI 기반 상품 검색 및 추천 시스템으로, 텍스트/이미지 기반 검색과 광고 영상 분석을 통한 상품 검색 기능을 제공하는 프로젝트입니다.

---

## 🎯 주요 담당 업무

### 1. AI 기반 상품 검색 시스템 개발

#### 텍스트 기반 검색

- Google Gemini LLM을 활용한 자연어 질의 분석
- 사용자 질의에서 카테고리, 옵션, 가격 조건 자동 추출
- 유사 질문 생성 및 검색 이력 관리
- Qdrant 벡터 DB를 활용한 의미 기반 유사도 검색
- 가중치 기반 검색 결과 정렬 (태그, 텍스트, 이미지 가중치 조정 가능)

#### 이미지 기반 검색

- 이미지 업로드를 통한 유사 상품 검색
- 벡터 임베딩 기반 이미지 유사도 비교
- Warehouse 이미지 관리 및 검색 로직 구현

### 2. 광고 영상 분석 및 검색 시스템 (2차 POC)

#### 영상 프레임 추출 및 분석

- OpenCV를 활용한 영상 프레임 추출
- 추출된 프레임 이미지 리사이즈 및 암호화 처리
- GCS(Google Cloud Storage)에 이미지 저장 및 관리

#### 이미지 클러스터링

- CLIP 모델을 활용한 이미지 클러스터링
- 대표 프레임 선정으로 처리 효율성 향상
- 클러스터링된 데이터 기반 검색 최적화

#### VertexAI 멀티모달 임베딩

- VertexAI를 활용한 이미지 + 메타데이터 임베딩 생성
- Google Gemini 프롬프트를 통한 이미지 분석
- 분석 결과를 활용한 상품 검색 정확도 향상

#### 영상 기반 검색

- 영상 재생 중 특정 시점의 프레임 기반 상품 검색
- 텍스트/영상 검색 분기 처리
- Signed URL을 통한 보안 강화
- 검색 결과에 추출된 이미지 및 재생 시간 정보 포함

### 3. 비동기 처리 및 성능 최적화

#### Celery 비동기 처리

- Celery를 활용한 영상 분석 백그라운드 작업 처리
- Flower를 통한 작업 모니터링
- Task 실행 기록 저장 및 관리

#### Redis 캐싱

- 프레임 목록 조회 시 Redis 캐시 적용
- 반복 조회 성능 향상

### 4. 데이터 처리 파이프라인 (ShopperHouseDataPy)

#### 데이터 전처리

- 상품 데이터 처리 CLI 개발
- 카테고리/속성 데이터 관리
- 리뷰 분석 및 요약 자동화

#### 임베딩 파이프라인

- sentence-transformers, GoogleSigLIP 모델을 활용한 이미지 임베딩
- 이미지 스플릿 및 배치 처리
- Qdrant 벡터 DB에 임베딩 데이터 저장

#### 이미지 임베딩 모델 교체

- 기존 모델에서 GoogleSigLIP로 교체
- 임베딩 성능 및 정확도 향상
- 모델 다운로드 경로 환경변수 관리

### 5. 인프라 및 DevOps

#### Docker 환경 구축

- local, dev 환경별 Docker 설정
- docker-compose를 활용한 멀티 컨테이너 관리
- 도커 이미지 경량화 작업

#### GCS 연동

- Google Cloud Storage 관리 클래스 구현
- Signed URL 생성 및 관리
- 이미지 업로드/다운로드 로직 구현

#### CI/CD

- Git Actions를 활용한 자동화 배포
- 환경 변수 관리 및 설정 최적화

## 🔍 기술적 도전 과제 및 해결

### 1. 영상 프레임 중복 제거

**문제**: 연속된 영상 프레임에서 유사한 이미지가 과도하게 추출됨  
**해결**: CLIP 모델을 활용한 이미지 클러스터링으로 대표 프레임만 선별

### 2. 이미지 임베딩 성능 개선

**문제**: 기존 임베딩 모델의 정확도 부족  
**해결**: GoogleSigLIP 모델로 교체하여 검색 정확도 향상

### 3. VertexAI 텍스트 임베딩 제약

**문제**: VertexAI 텍스트 임베딩의 32단어 제약  
**해결**: 텍스트 분할 처리 및 에러 핸들링 구현

### 4. 영상 분석 처리 시간

**문제**: 영상 프레임 추출 및 분석에 긴 시간 소요  
**해결**: Celery 비동기 처리로 백그라운드에서 작업 수행
