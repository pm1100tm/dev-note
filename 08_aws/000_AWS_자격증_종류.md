# AWS 자격증 종류와 학습 경로

> 확인 기준: 2026-09-11. 시험 코드, 제공 언어, 개편·종료 일정은 응시 전에 공식 페이지에서 다시 확인한다.

## 1. 자격증 체계 이해하기

AWS 기술 자격증은 다음 네 범주로 구분한다. 모든 자격증을 순서대로 취득하는 과정은 아니며,
현재 경험과 목표 직무에 맞춰 선택한다.

| 구분 | 성격 | 학습 초점 |
| --- | --- | --- |
| Foundational | 입문 지식 | 클라우드 또는 AI 기본 개념 |
| Associate | 직무별 기술 기초 | 설계, 개발, 운영, 데이터, ML 구현 |
| Professional | 고급 실무 | 복잡한 시스템의 설계·구현·운영 |
| Specialty | 특정 분야 심화 | 보안, 네트워크 등 전문 영역 |

**Specialty는 Professional 다음에 반드시 거치는 '4단계'가 아니다.**
특정 분야의 전문성을 다루는 별도 범주이며, 체감 난이도는 해당 분야의 경험에 따라 달라진다.

기술 자격증 외에 AI 도입과 비즈니스 전략을 다루는 Business 범주도 있다.
공식 목록에는 AI Business Strategist가 베타 시험으로 안내되어 있다.
[AWS 자격증 전체 목록](https://aws.amazon.com/certification/)

## 2. 범주별 자격증 비교

아래 이름에는 공통으로 `AWS Certified`가 붙는다. 시험 코드는 교재와 강의를 고를 때 버전을 구분하는 기준이다.
[공식 시험 가이드](https://docs.aws.amazon.com/aws-certification/latest/examguides/aws-certification-exam-guides.html)

### Foundational — 기본 개념

| 자격증 | 시험 코드 | 주요 학습 내용 |
| --- | --- | --- |
| Cloud Practitioner | CLF-C02 | 클라우드, AWS 서비스, 보안·비용 기초 |
| AI Practitioner | AIF-C01 | AI·ML·생성형 AI 개념과 활용 |

클라우드 용어부터 익혀야 한다면 Cloud Practitioner, AI 활용 개념을 이해하려면 AI Practitioner를 검토한다.
두 시험은 초점이 다르므로 둘 다 취득해야 하는 관계는 아니다.

### Associate — 직무별 기술 역량

| 자격증 | 시험 코드 | 주요 학습 내용 |
| --- | --- | --- |
| Solutions Architect – Associate | SAA-C03 | 가용성·보안·성능·비용을 고려한 설계 |
| Developer – Associate | DVA-C02 | 애플리케이션 개발·배포·디버깅 |
| CloudOps Engineer – Associate | SOA-C03 | 워크로드 배포·관리·운영 |
| Data Engineer – Associate | DEA-C01 | 데이터 파이프라인과 저장소 |
| Machine Learning Engineer – Associate | MLA-C01 | ML 솔루션 구현·배포·유지관리 |

기존 자료의 **SysOps Administrator – Associate(SOA-C02)** 대신 현재 가이드에 안내된
**CloudOps Engineer – Associate(SOA-C03)**를 기준으로 정리했다.

MLA 시험은 개편 중이다. MLA-C02 베타는 2026-09-29 시작 예정이며,
베타 기간 중 기존 MLA-C01의 한국어·일본어·중국어 간체 시험도 제공된다.
교재 선택 시 응시 언어와 버전을 함께 확인한다.
[공식 시험 코드 및 MLA 개편 안내](https://docs.aws.amazon.com/aws-certification/latest/examguides/aws-certification-exam-guides.html)

### Professional — 고급 설계와 구현

| 자격증 | 시험 코드 | 주요 학습 내용 |
| --- | --- | --- |
| Solutions Architect – Professional | SAP-C02 | 복잡한 분산 시스템 설계 |
| DevOps Engineer – Professional | DOP-C02 | 배포·운영 자동화와 시스템 관리 |
| Generative AI Developer – Professional | AIP-C01 | 생성형 AI 솔루션 설계·구현·배포 |

설계에 집중하면 Solutions Architect, 배포와 운영 자동화에 집중하면 DevOps Engineer,
생성형 AI 애플리케이션 구현에 집중하면 Generative AI Developer를 검토한다.

### Specialty — 전문 영역 심화

| 자격증 | 시험 코드 | 주요 학습 내용 |
| --- | --- | --- |
| Advanced Networking – Specialty | ANS-C01 | AWS·하이브리드 네트워크 설계 |
| Security – Specialty | SCS-C03 | 워크로드 보안과 데이터 보호 |

Advanced Networking은 공식 목록에 **2026-12-31 종료 예정**으로 표시되어 있다.
준비 전에 응시 가능 일정을 확인한다.
[AWS 자격증 목록의 종료 안내](https://aws.amazon.com/certification/)

## 3. 목표 직무별 학습 경로

아래는 이 문서의 학습 제안이며, 모든 시험을 취득해야 한다는 의미는 아니다.
AWS도 직무에 따라 서로 다른 경로를 안내한다.
[AWS 직무별 자격증 경로](https://d1.awsstatic.com/onedam/marketing-channels/website/aws/en_US/certification/approved/pdfs/AWS_certification_paths_2025.pdf)

| 목표 | 시작점 | 경험을 쌓은 뒤 확장할 영역 |
| --- | --- | --- |
| 클라우드 입문 | Cloud Practitioner | 관심 직무의 Associate |
| 백엔드 개발 | Solutions Architect Associate 또는 Developer Associate | DevOps Professional |
| 인프라 운영 | CloudOps Associate | DevOps Professional 또는 Security Specialty |
| 아키텍처 설계 | Solutions Architect Associate | Solutions Architect Professional |
| 데이터 엔지니어링 | Data Engineer Associate | ML 구현 또는 아키텍처 설계 |
| ML 엔지니어링 | Machine Learning Engineer Associate | 생성형 AI 개발 또는 데이터 엔지니어링 |
| 생성형 AI 개발 | AI 기초와 AWS 애플리케이션 개발 실습 | Generative AI Developer Professional |

### Java·Spring Boot 개발자의 선택 예시

AWS 전체 구조를 이해하는 것이 우선이면 **SAA부터**, 이미 AWS를 사용하며 개발·배포 지식을
정리하려면 **DVA부터** 검토할 수 있다.

- VPC, EC2, RDS를 배치하고 장애에 대비하는 방법을 배우고 싶은가? → SAA
- AWS SDK, 서버리스, 배포와 디버깅을 배우고 싶은가? → DVA
- 운영 모니터링과 장애 대응을 담당하는가? → CloudOps
- CI/CD와 인프라 자동화를 더 깊게 다루려는가? → 실무 경험을 쌓으며 DOP 검토

학습과 함께 작은 Spring Boot API를 배포하고 로그, 모니터링, 권한, 배포 자동화를 직접 구성해 보면
서비스 이름뿐 아니라 설계 선택의 이유를 이해하는 데 도움이 된다.

## 4. 기존 자료를 볼 때 주의할 변경사항

### 종료된 자격증

아래 항목은 과거 자격증으로 구분한다. 신규 응시 대상으로 선택하지 않는다.

| 자격증 | 과거 시험 코드 | 종료 시점 |
| --- | --- | --- |
| Data Analytics – Specialty | DAS-C01 | 2024년 4월 |
| Database – Specialty | DBS-C01 | 2024년 4월 |
| SAP on AWS – Specialty | PAS-C01 | 2024년 4월 |
| Machine Learning – Specialty | MLS-C01 | 2026년 3월 31일 |

시험 종료와 기존에 취득한 자격증의 즉시 무효화는 다르다. 보유 자격의 유효 상태는 별도로 확인한다.
[2024년 Specialty 종료 공지](https://aws.amazon.com/blogs/training-and-certification/aws-certification-retirements-and-launches/),
[Machine Learning Specialty 종료 안내](https://aws.amazon.com/certification/certified-machine-learning-specialty/)

### 이름과 시험 코드 혼동 주의

- `SAP-C02`는 **Solutions Architect – Professional**의 시험 코드다.
- 종료된 **SAP on AWS – Specialty**의 시험 코드는 `PAS-C01`이다.
- Security는 기존 `SCS-C02` 대신 현재 가이드의 `SCS-C03`를 확인한다.
- 같은 자격증도 개편되면 시험 코드와 출제 범위가 달라질 수 있다. 구버전 강의 구매 전에 확인한다.

## 5. 준비 전 확인 순서

1. 목표 직무를 정하고 우선 준비할 자격증 하나를 선택한다.
2. 공식 페이지에서 시험 코드, 제공 언어, 개편·종료 여부를 확인한다.
3. 해당 버전의 시험 가이드로 출제 영역을 파악한다.
4. 부족한 영역을 학습하고 관련 서비스를 직접 사용해 본다.
5. 공식 연습 자료로 이해도를 확인한 뒤 응시 일정을 정한다.

응시료와 시험 시간 등 변동 가능한 정보는 아래 공식 페이지를 기준으로 확인한다.

- [AWS Certification](https://aws.amazon.com/certification/)
- [AWS Certification Exam Guides](https://docs.aws.amazon.com/aws-certification/latest/examguides/aws-certification-exam-guides.html)
- [AWS Skill Builder](https://skillbuilder.aws/)
