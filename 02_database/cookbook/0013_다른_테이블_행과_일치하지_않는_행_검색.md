# 다른 테이블 행과 일치하지 않는 행 검색

예를 들어 사원이 없는 부서를 찾고자 합니다.

```sql
select
    d.*
from
    dept as d
    left outer join emp as e
        on e.deptno = d.deptno
where
    e.deptno is null
;
```

`NOT EXISTS` 또는 `EXCEPT`로도 같은 대상을 찾을 수 있습니다. `LEFT JOIN ... IS NULL`은
`dept`의 다른 열을 함께 반환하기 쉽다는 장점이 있습니다. 단, 조인 조건에 사용할
컬럼이 NULL을 허용하면 조건을 명확히 해야 합니다.

아래의 쿼리는 앞선 레시피이며, 이 결과 셋에는 emp 테이블의 열을 가져올 수 없습니다.

```sql
select
    d.deptno,
    d.dname,
    d.loc
from
    dept as d
where
    not exists (
        select 1 from emp as e where e.deptno = d.deptno
    )
;
```
