# codex 나만의 스킬 만들기

내장 이미지 생성 도구로 새 다이어그램을 만들었으며, ECS 서비스의 CPU 기반 오토스케일링 흐름과 하단 EC2 Capacity Provider 안내를 프레임 안에 모두 넣었습니다.

매번 같은 크기 원칙을 적용하려면 `$skill-creator`로 개인 스킬을 만드는 방식이 좋습니다. OpenAI의 스킬은 폴더의 `SKILL.md`에 활성화 조건과 작업 절차를 정의합니다. [공식 Skills 문서](https://developers.openai.com/plugins/build/skills)

예를 들어 아래처럼 요청하면 됩니다.

```
$skill-creator 다음 개인 스킬을 만들어줘.

이름: diagram-image-sizing
목적: 학습 문서용 다이어그램을 생성하거나 편집할 때,
항상 읽기 좋은 비율과 해상도로 결과를 만든다.

활성화 조건:
- 다이어그램, 아키텍처 이미지, 이미지 생성 또는 이미지 편집 요청

규칙:
- 가로형 다이어그램은 기본 4:3 비율을 사용한다.
- 세로형 다이어그램은 기본 3:4 비율을 사용한다.
- 긴 변은 최대 1200px을 권장한다.
- 이미지를 늘이거나 잘라서 비율을 바꾸지 않는다.
- 모든 텍스트, 화살표, 하단 안내 상자는 안전 여백 안에 둔다.
- 생성 후 실제 가로·세로 크기를 확인한다.
- 요소가 잘렸거나 글자가 읽기 어려우면 자르지 말고 다시 생성한다.
- 래스터 이미지는 imagegen을 사용하고, 저장 후 비율을 유지한 채
  필요하면 긴 변만 축소한다.
```
