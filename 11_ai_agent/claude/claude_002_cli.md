# Claude Code CLI 자주 쓰는 명령어

- Claude Code는 현재 작업 폴더를 프로젝트의 기본 범위로 사용합니다.
- 먼저 대상 저장소로 이동한 뒤 명령을 실행하는 것이 안전합니다.

```shell
cd ~/Desktop/my-project
```

> 이 문서는 2026-10-01에 [Claude Code 공식 CLI 레퍼런스](https://code.claude.com/docs/en/cli-usage)를
> 기준으로 확인했습니다. Claude Code는 자주 변경되므로, 설치된 버전의
> 상세 옵션은 `claude --help`로 함께 확인합니다.

## 대화 시작과 요청 전달

| 명령어                                     | 사용할 때                                          | 설명                                                                  |
| ------------------------------------------ | -------------------------------------------------- | --------------------------------------------------------------------- |
| `claude`                                   | 프로젝트를 살펴보거나 여러 차례 대화하며 작업할 때 | 대화형 세션을 시작합니다. 이후 프롬프트를 입력합니다.                 |
| `claude "요청"`                            | 시작과 동시에 첫 작업을 전달할 때                  | 대화형 세션을 열면서 문자열을 첫 프롬프트로 보냅니다.                 |
| `claude -p "요청"`                         | 스크립트, CI처럼 결과만 받고 종료할 때             | 비대화형으로 요청을 실행하고 응답을 표준 출력에 표시한 뒤 종료합니다. |
| `파일을_출력하는_명령 \| claude -p "요청"` | 로그나 명령 출력 내용을 바로 분석할 때             | 파이프로 전달된 텍스트와 함께 요청을 처리합니다.                      |

다음은 현재 프로젝트의 구조만 설명하도록 요청하는 예입니다.

```shell
claude "프로젝트 구조와 실행 방법을 설명해 주세요. 파일은 변경하지 마세요."
```

로그를 분석할 때는 파일 안에 토큰, 개인정보, 운영 데이터가
없는지 확인한 뒤 필요한 부분만 전달합니다.

```shell
tail -n 200 application.log | claude -p "오류 원인 후보를 설명해 주세요."
```

## 이전 작업 이어 하기

| 명령어                          | 사용할 때                                      | 설명                                                                             |
| ------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------- |
| `claude -c`                     | 같은 프로젝트에서 방금 하던 대화를 계속할 때   | 현재 디렉터리의 가장 최근 대화 세션을 이어서 엽니다.                             |
| `claude -c -p "요청"`           | 최근 맥락을 이어 자동화 요청을 한 번 실행할 때 | 최근 세션의 맥락으로 비대화형 요청을 실행합니다.                                 |
| `claude -r "세션_ID_또는_이름"` | 특정 과거 작업을 다시 열 때                    | 지정한 세션 ID 또는 세션 이름의 대화를 재개합니다.                               |
| `claude -n "세션_이름"`         | 나중에 찾기 쉽게 작업에 이름을 붙일 때         | 새 세션의 표시 이름을 지정합니다. 지정한 이름은 `--resume`에 사용할 수 있습니다. |

```shell
claude -n "login-bug-investigation"
claude -r "login-bug-investigation" "앞서 확인한 원인 후보를 다시 검증해 주세요."
```

`-c`는 편리하지만 다른 작업의 대화가 이어질 수 있습니다.
기능이나 브랜치가 달라졌다면 새 세션을 시작하고 필요한 배경을
다시 전달하는 편이 이해하기 쉽고 안전합니다.

## 작업 범위와 권한 제어

Claude Code는 파일을 읽거나 명령을 실행하기 전에 권한을
요청할 수 있습니다. 특히 처음에는 읽기와 계획 위주로 시작하는
것을 권장합니다.

| 명령어 또는 옵션                  | 사용할 때                                          | 설명                                                                                      |
| --------------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `claude --permission-mode plan`   | 변경 전에 계획과 영향 범위를 검토할 때             | 계획 모드로 시작합니다. 구현보다 분석과 계획 수립에 적합합니다.                           |
| `claude --add-dir ../shared-lib`  | 현재 프로젝트 밖의 인접 소스도 함께 참조해야 할 때 | 지정한 디렉터리를 추가 작업 범위로 제공합니다. 경로의 파일 접근 권한이 넓어집니다.        |
| `claude --allowedTools "Read"`    | 반복해서 허용할 안전한 도구 범위가 명확할 때       | 지정한 도구는 추가 확인 없이 사용할 수 있게 합니다. 자동화에서는 최소 권한만 허용합니다.  |
| `claude --disallowedTools "Edit"` | 분석만 하고 파일 변경은 막아야 할 때               | 지정한 도구 사용을 금지합니다. 예를 들어 `Edit`을 막으면 파일 수정을 방지할 수 있습니다.  |
| `claude --model sonnet`           | 현재 세션에 사용할 모델을 선택할 때                | 모델 별칭 또는 전체 모델 ID를 지정합니다. 사용 가능한 모델은 계정과 시점에 따라 다릅니다. |

```shell
claude --permission-mode plan \
  "로그인 기능의 변경 방안과 테스트 범위를 제안해 주세요."
```

`--dangerously-skip-permissions`는 권한 확인을 건너뜁니다.
신뢰할 수 없는 저장소, 민감한 파일이 있는 환경, 일반적인
로컬 작업에서는 사용하지 않습니다.

## 비대화형 실행과 자동화

`-p` 모드는 셸 스크립트나 CI에서 사용하기 편합니다. 다만
자동화에 쓰기 전에는 대상 브랜치, 허용 도구, 출력 형식을
명시해야 합니다.

| 옵션                   | 사용할 때                              | 설명                                                                               |
| ---------------------- | -------------------------------------- | ---------------------------------------------------------------------------------- |
| `--output-format json` | 다른 프로그램이 결과를 읽어야 할 때    | 비대화형 응답을 JSON으로 출력합니다. 텍스트를 임의로 파싱하는 것보다 안정적입니다. |
| `--max-turns 3`        | 자동화가 너무 오래 실행되지 않게 할 때 | 비대화형 에이전트의 최대 작업 턴 수를 제한합니다.                                  |
| `--verbose`            | 자동화 실행 과정이나 문제를 조사할 때  | 턴별 상세 출력을 표시합니다. 로그에 민감한 내용이 남지 않도록 주의합니다.          |

```shell
claude -p --max-turns 3 --output-format json \
  "테스트 실패 원인을 요약하고, 수정이 필요한 파일만 알려 주세요."
```

CI에서 파일이나 명령 실행을 허용할 때는 `--allowedTools`로
꼭 필요한 도구만 허용합니다. API 키와 토큰은 코드·명령 기록·출력에
남기지 않습니다.

## 설치, 인증, 상태 확인

| 명령어                      | 사용할 때                                          | 설명                                                                               |
| --------------------------- | -------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `claude --version`          | 설치된 버전을 확인할 때                            | Claude Code 버전을 출력합니다. 문제 보고나 문서 확인 전에 유용합니다.              |
| `claude --help`             | 옵션이나 하위 명령을 확인할 때                     | 설치된 CLI가 제공하는 도움말을 출력합니다.                                         |
| `claude auth login`         | 로그아웃했거나 다른 인증 방식으로 다시 로그인할 때 | Anthropic 계정 인증을 시작합니다. Console 사용자는 `--console`을 붙일 수 있습니다. |
| `claude auth status --text` | 로그인 여부를 빠르게 확인할 때                     | 현재 인증 상태를 사람이 읽기 쉬운 형식으로 표시합니다.                             |
| `claude auth logout`        | 공용 장비 사용을 끝내거나 계정을 바꿀 때           | 로컬 Claude Code 인증 정보를 로그아웃합니다.                                       |
| `claude doctor`             | 실행, 설치, 설정 문제를 진단할 때                  | 세션을 열지 않고 설치 상태와 설정 파일 오류를 읽기 전용으로 검사합니다.            |
| `claude update`             | 최신 버전으로 즉시 업데이트할 때                   | Claude Code 업데이트를 실행합니다.                                                 |

## MCP 서버 관리

MCP(Model Context Protocol)는 Claude Code에 외부 도구나
데이터 소스를 연결하는 방식입니다. 서버가 접근할 수 있는 파일,
네트워크, 계정 권한을 확인한 뒤 추가해야 합니다.

| 명령어                                   | 사용할 때                          | 설명                                                                 |
| ---------------------------------------- | ---------------------------------- | -------------------------------------------------------------------- |
| `claude mcp`                             | MCP 관련 하위 명령을 찾아볼 때     | MCP 서버 설정 관리 명령의 도움말을 엽니다.                           |
| `claude mcp add <이름> -- <명령> [인수]` | 로컬 stdio MCP 서버를 등록할 때    | 이름과 서버 실행 명령을 등록합니다. `--` 뒤는 MCP 서버에 전달됩니다. |
| `claude mcp list`                        | 등록한 MCP 서버를 점검할 때        | 구성된 MCP 서버 목록과 상태를 확인합니다.                            |
| `claude mcp remove <이름>`               | 더 이상 쓰지 않는 서버를 해제할 때 | 지정한 MCP 서버 설정을 제거합니다.                                   |
| `claude mcp login <이름>`                | OAuth를 쓰는 등록 서버에 인증할 때 | 대화형 세션 없이 해당 MCP 서버의 로그인 흐름을 시작합니다.           |

MCP 전용 옵션과 전송 방식은 [Claude Code MCP 공식 문서](https://code.claude.com/docs/en/mcp)에서
확인합니다. 예시의 API 키 자리에는 실제 비밀값을 명령줄에 직접
넣지 않고, 운영체제의 안전한 비밀 관리 방식을 사용합니다.

## 대화 중 자주 쓰는 슬래시 명령

아래 명령은 셸이 아니라 `claude`로 시작한 대화형 세션 안에서
입력합니다.

| 명령어         | 사용할 때                                        | 설명                                                                                |
| -------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------- |
| `/help`        | 사용 가능한 기능을 찾을 때                       | 대화형 명령과 사용법을 표시합니다.                                                  |
| `/clear`       | 현재 대화의 맥락을 비우고 새 주제를 시작할 때    | 화면과 현재 대화 맥락을 정리합니다. 과거 세션 기록 자체를 삭제하는 명령은 아닙니다. |
| `/compact`     | 긴 대화로 컨텍스트가 커졌을 때                   | 지금까지의 핵심 내용을 압축해 이후 대화에 사용할 맥락을 줄입니다.                   |
| `/status`      | 모델, 권한 모드, 사용량 등 현재 상태를 확인할 때 | 현재 세션의 주요 상태 정보를 표시합니다.                                            |
| `/model`       | 세션 중 모델을 바꾸거나 확인할 때                | 사용 가능한 모델을 확인하고 선택합니다.                                             |
| `/permissions` | 도구 권한 설정을 확인하거나 조정할 때            | 현재 세션의 권한 관련 설정을 봅니다.                                                |
| `/resume`      | 대화형 화면에서 이전 세션을 고를 때              | 저장된 세션 목록에서 이어서 작업할 대화를 선택합니다.                               |
| `/exit`        | 작업을 끝낼 때                                   | 대화형 세션을 종료합니다. `Ctrl+C`도 종료에 사용할 수 있습니다.                     |

슬래시 명령의 구성은 버전에 따라 달라질 수 있습니다. 최신 목록과
설명은 [대화형 모드 공식 문서](https://code.claude.com/docs/en/interactive-mode)를
확인합니다.
