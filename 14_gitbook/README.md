# GitBook

GitBook으로 기술 문서를 작성·검토·게시하고 Git 저장소와 동기화하는 방법을 정리한다.
이 저장소에서는 Markdown 문서를 Git으로 관리하고, GitBook을 통해 탐색 가능한 문서
사이트로 제공한다.

## 이 폴더에서 다루는 내용

- GitBook의 기본 개념과 문서화에 적합한 상황
- 시각 편집 방식과 docs-as-code 방식의 차이
- GitHub 저장소, 브랜치, 콘텐츠 디렉터리를 GitBook과 연결하는 방법
- `SUMMARY.md`, `gitbook-docs.yaml`, `.gitbook.yaml`의 역할과 운영 시 주의점
