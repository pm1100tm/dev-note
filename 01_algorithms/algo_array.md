# 배열(Array)

배열은 원소를 순서대로 저장하고 인덱스로 접근하는 자료구조입니다. 일반적인 배열은 같은 크기의 원소를 연속된 메모리 공간에 배치하므로,
인덱스를 이용한 임의 접근(random access)이 빠릅니다.

Python의 `list`는 엄밀히 말해 동적 배열이며 객체 자체가 아니라 객체에 대한 참조를 저장합니다. 크기가 부족하면 더 큰 공간을
할당하고 기존 참조를 복사하므로, 끝에 추가하는 `append`는 한 번의 연산만 보면 `O(n)`일 수 있지만 여러 연산에 걸친
**분할 상환 시간 복잡도(amortized complexity)**는 `O(1)`입니다.

## 주요 연산과 복잡도

| 연산               | 시간 복잡도             | 설명                                        |
| ------------------ | ----------------------- | ------------------------------------------- |
| 인덱스로 조회·수정 | `O(1)`                  | 시작 주소와 인덱스로 위치를 계산한다.       |
| 값으로 탐색        | `O(n)`                  | 정렬 등의 추가 조건이 없다면 순차 탐색한다. |
| 끝에 추가          | 분할 상환 `O(1)`        | 공간 확장 시에는 `O(n)`이 필요할 수 있다.   |
| 끝에서 삭제        | `O(1)`                  | 마지막 원소만 제거한다.                     |
| 중간 삽입·삭제     | `O(n)`                  | 뒤쪽 원소를 이동해야 한다.                  |
| 정렬               | 일반적으로 `O(n log n)` | 알고리즘과 입력에 따라 달라질 수 있다.      |

## 정렬

배열 문제에서는 정렬을 전처리로 사용해 탐색이나 비교를 단순화하는 경우가 많습니다. 다만 모든 정렬 알고리즘이 항상
`O(n log n)`인 것은 아닙니다.

| 알고리즘  | 평균         | 최악         | 추가 공간        | 안정 정렬       |
| --------- | ------------ | ------------ | ---------------- | --------------- |
| 퀵 정렬   | `O(n log n)` | `O(n²)`      | 구현에 따라 다름 | 일반적으로 아님 |
| 병합 정렬 | `O(n log n)` | `O(n log n)` | `O(n)`           | 가능            |
| 힙 정렬   | `O(n log n)` | `O(n log n)` | `O(1)`           | 아님            |

안정 정렬(stable sort)은 값이 같은 원소들의 기존 순서를 유지합니다. 여러 기준으로 연속해서 정렬하거나 원소에 부가 정보가
있을 때 중요합니다.

### 퀵 정렬의 핵심

퀵 정렬은 기준값인 피벗(pivot)을 선택하고, 피벗보다 작은 값과 큰 값을 분할(partition)한 뒤 각 구간을 재귀적으로 정렬합니다.
피벗이 계속 최솟값이나 최댓값으로 선택되면 분할이 한쪽으로 치우쳐 최악의 경우 `O(n²)`이 됩니다. 무작위 피벗이나 중앙값에
가까운 피벗을 선택하면 이러한 위험을 줄일 수 있습니다.

## 이진 탐색

이진 탐색은 **탐색 대상이 정렬되어 있을 때** 검색 범위를 절반씩 줄이는 알고리즘입니다. 시간 복잡도는 `O(log n)`,
반복문으로 구현할 때 추가 공간 복잡도는 `O(1)`입니다.

오름차순 배열에서의 규칙은 다음과 같습니다.

- 1. `left`와 `right` 사이의 중간 인덱스 `mid`를 구한다.
- 2. `values[mid] == target`이면 `mid`를 반환한다.
- 3. 중간값이 목표값보다 작으면 `left = mid + 1`로 오른쪽 절반을 탐색한다.
- 4. 중간값이 목표값보다 크면 `right = mid - 1`로 왼쪽 절반을 탐색한다.

```python
def binary_search(values: list[int], target: int) -> int:
    left, right = 0, len(values) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if values[mid] == target:
            return mid
        if values[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1


assert binary_search([1, 3, 5, 7, 9], 7) == 3
assert binary_search([1, 3, 5, 7, 9], 4) == -1
```

### 구현 시 주의점

- 반복 조건과 탐색 구간의 정의를 일관되게 유지합니다. 위 코드는 닫힌 구간 `[left, right]`를 사용합니다.
- 중복 값 중 첫 위치나 마지막 위치를 찾아야 한다면 값을 발견한 뒤에도 탐색을 계속해야 합니다.
- 정렬 비용이 `O(n log n)`이므로 한 번만 탐색한다면 정렬 후 이진 탐색이 순차 탐색보다 비쌀 수 있습니다.
