# 알고리즘과 자료구조

문제를 해결하는 데 자주 사용하는 알고리즘과 자료구조를 정리합니다. 단순한 정의 암기보다 **어떤 조건에서 사용할 수 있는지**,
**시간·공간 복잡도는 얼마인지**, **구현할 때 무엇을 주의해야 하는지**를 중심으로 다룹니다.

## 문서 목록

### 알고리즘

- [배열(Array)](algo_array.md): 배열의 특성, 주요 연산의 복잡도, 정렬과 이진 탐색
- [탐욕 알고리즘(Greedy Algorithm)](algo_greedy.md): 적용 조건, 증명 관점, 동전 문제와 반례

### 자료구조

- [LRU 캐시(Least Recently Used)](data_lru_cache.md): 캐시 교체 정책과 Python 구현
- [다중집합(Multiset)](data_multiset.md): 원소별 빈도 관리와 `collections.Counter` 활용

## 문제 풀이 체크리스트

- 1. 입력 크기와 값의 범위를 확인한다.
- 2. 허용 가능한 시간 복잡도와 공간 복잡도를 추정한다.
- 3. 정렬 여부, 중복 허용 여부, 원소의 삽입·삭제·조회 빈도를 확인한다.
- 4. 선택한 알고리즘이 정답을 보장하는 조건을 설명하거나 증명한다.
- 5. 빈 입력, 중복 값, 최솟값·최댓값 등 경계 조건을 테스트한다.

> 복잡도는 구현과 전제 조건에 따라 달라집니다. 예를 들어 배열 탐색은 일반적으로 `O(n)`이지만, 정렬된 배열에서는
> 이진 탐색으로 `O(log n)`에 수행할 수 있습니다.
