# EXPOSE와 ports

`EXPOSE`와 Compose의 `ports`는 모두 포트와 관련 있지만, 외부 접근을 허용하는 동작은
다르다. 특히 `EXPOSE`만으로 호스트 포트가 열리지 않는다는 점이 중요하다.

| 설정                   | 위치       | 의미                                                                 |
| ---------------------- | ---------- | -------------------------------------------------------------------- |
| `EXPOSE 8080`          | Dockerfile | 컨테이너가 사용할 포트를 문서화한다.                                 |
| `expose: ["8080"]`     | Compose    | 컨테이너 포트 정보를 선언한다. 같은 네트워크 통신에는 필수가 아니다. |
| `ports: ["8080:8080"]` | Compose    | 호스트 포트를 컨테이너 포트로 게시한다.                              |

## 예시

```yaml
services:
  api:
    image: example/api:1.0
    expose:
      - '8080'
    networks: [internal]

  web:
    image: nginx:1.27-alpine
    ports:
      - '127.0.0.1:8080:80'
    networks: [internal]

networks:
  internal:
```

- `web`은 호스트의 `127.0.0.1:8080`으로 접근할 수 있다.
- `api`는 같은 `internal` 네트워크에서 `api:8080`으로 접근할 수 있다.
- `api`에 `expose`가 없어도 애플리케이션이 8080에서 리스닝하면 같은 네트워크에서 연결 가능하다.
- 모든 인터페이스에 노출해야 할 근거가 없다면 `127.0.0.1:...`으로 바인딩해 공개 범위를 줄인다.
