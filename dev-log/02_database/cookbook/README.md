# SQL Cookbook

반복해서 사용하는 SQL 패턴을 짧은 예제와 함께 정리한 모음입니다. 대부분 PostgreSQL
문법을 기준으로 하며, MySQL·Oracle 등에서 함수나 집합 연산이 다른 경우 본문에
차이를 표시합니다.

## 주제

- 문자열 결합, NULL 처리, 타입 변환
- 부분 문자열·NULL·조건식 기준 정렬
- `UNION`, `EXCEPT`, `DISTINCT`
- 서브쿼리와 일치하지 않는 행 검색
- 카디널리티, 데카르트 곱, 집계와 조인
- `STRING_AGG`를 이용한 1:N 결과 집계

예제는 `emp`, `dept`, `emp_bonus` 샘플 테이블을 전제로 합니다. 실행 전에 테이블의
컬럼 타입과 데이터 분포를 자신의 환경에 맞게 확인하세요.
