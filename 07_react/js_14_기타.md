# JavaScript 기타 문법

## in 연산자와 includes

`in`은 객체에 속성이 존재하는지 확인하며 프로토타입 체인도 검사한다. 배열에서는 값이 아니라
인덱스 또는 속성 이름을 확인한다.

```js
const items = ['apple', 'banana'];

console.log(0 in items); // true
console.log('apple' in items); // false
console.log(items.includes('apple')); // true
```

객체 자신의 속성만 확인하려면 `Object.hasOwn(object, key)`를 사용한다.

```js
const user = { name: 'Jin' };
console.log(Object.hasOwn(user, 'name')); // true
```

## 구조 분해와 전개 연산자

구조 분해는 배열이나 객체에서 필요한 값을 꺼내고, 전개 연산자는 여러 값을 펼쳐 새 배열·객체를
만든다. 둘 다 얕은 복사라는 점을 기억한다.

```js
const { name, ...profile } = user;
const copiedUser = { ...user, name: 'Kim' };
const allItems = [...firstItems, ...secondItems];
```

## 부동소수점 비교

소수는 이진 부동소수점 표현 때문에 기대한 값과 정확히 같지 않을 수 있다. 금액처럼 정확성이 필요한
값은 정수 단위로 저장하고, 근삿값 비교가 필요하면 `Number.EPSILON`을 활용한다.

```js
const isAlmostEqual = (left, right) => Math.abs(left - right) < Number.EPSILON;

console.log(isAlmostEqual(0.1 + 0.2, 0.3)); // true
```
