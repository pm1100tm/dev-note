# JavaScript 자료구조와 컬렉션

자료구조는 데이터를 저장하고 접근하는 방식이고, 컬렉션은 여러 값을 다루기 위한 자료구조의
구체적인 도구다. 데이터의 접근 방식과 중복 허용 여부에 맞춰 선택한다.

| 상황 | 권장 컬렉션 | 이유 |
| --- | --- | --- |
| 순서가 있는 목록 | Array | 인덱스 접근과 배열 메서드 |
| 키로 값을 찾음 | Map 또는 Object | 키-값 저장 |
| 중복 없는 값 | Set | 값의 유일성 보장 |
| 화면 요소 목록 | DOM 컬렉션 | DOM API가 반환 |

Array는 순서가 있는 목록, Map은 임의 타입의 키에 연결한 값, Set은 중복 없는 값에 적합하다.
Object는 JSON과 설정값처럼 문자열 키의 단순 레코드에 적합하다.

컬렉션 선택 전에는 다음을 확인한다.

- 순서가 중요한가?
- 키의 타입이 문자열로 제한되는가?
- 중복을 허용하는가?
- 조회, 삽입, 삭제 중 어떤 작업이 많은가?
