# JavaScript 핵심 기초

JavaScript는 웹 브라우저와 서버에서 실행되는 동적 타입 언어다. 함수는 값으로 다룰 수 있으며,
객체와 함수는 참조 타입이라는 특징을 이해하면 React 코드의 동작도 더 쉽게 파악할 수 있다.

## 변수와 값

- `const`는 재할당하지 않는 변수에 기본으로 사용한다.
- `let`은 값이 바뀌어야 할 때 사용한다.
- `var`는 함수 스코프와 호이스팅 특성 때문에 새 코드에서는 피한다.
- 원시 값은 값 자체로 비교되고, 객체·배열·함수는 참조로 비교된다.

```js
const user = { name: 'Jin' };
const copied = user;

copied.name = 'Kim';
console.log(user.name); // Kim
```

## 일급 함수와 고차 함수

함수는 변수에 담고, 인자로 전달하고, 반환할 수 있다. 함수를 인자로 받거나 반환하는 함수를
고차 함수라고 한다.

```js
function repeat(count, action) {
  for (let index = 0; index < count; index += 1) {
    action(index);
  }
}

repeat(3, (index) => console.log(index));
```

## truthy, falsy, nullish

`false`, `0`, `''`, `null`, `undefined`, `NaN`은 falsy다. `??`는 `null` 또는 `undefined`일
때만 기본값을 사용하므로, `0`이나 빈 문자열도 유효한 값일 때 `||`보다 적합하다.

```js
const page = 0;
const withOr = page || 1; // 1
const withNullish = page ?? 1; // 0
```

## 불변성

객체를 직접 변경하지 않고 새 객체를 만들면 변경 지점을 추적하기 쉽다. React state도 이 방식으로
업데이트해야 변경 감지와 메모이제이션이 예측 가능해진다.

```js
const nextUser = { ...user, name: 'Lee' };
const nextItems = [...items, newItem];
```
