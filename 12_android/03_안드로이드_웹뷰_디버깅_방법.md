# 안드로이드 웹뷰 앱 디버깅

- .apk 파일을 build type = debug 로 빌드한다.
- 에뮬레이터를 실행하여 .apk 파일을 설치한다.
- `chrome://inspect/#devices` 에 접속한다.
- inspect

## PC에서 에뮬레이이터 실행

[debug](./assets/debug_01.png)

<br>

## chrome://inspect/#devices 접속

스크린샷과 같이 Remote Target 하단에 에뮬레이터 정보와 WebView 접속 주소가 표시된다.

[debug](./assets/debug_02.png)

<br>

## inspect 버튼을 클릭하여 브라우저에서 디버깅이 가능하다.

에뮬레이터에서 입력하면, 브라우저의 디버그 화면에서 똑같이 입력되는 것을 확인할 수 있다.

[debug](./assets/debug_03.png)
