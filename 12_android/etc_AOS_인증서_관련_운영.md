# AOS 애플리케이션 인증서(디지털 서명) 관리

- 앱을 만든 개발자의 신원을 증명
- 앱 위변조 보장하는 디지털 서명
- 앱 설치 파일을 생성할 때 .jks 확장자의 파일(키스토어 파일) 사용

## 키스토어 파일(.jks) 정보 및 보관

`<filename>.jks`

- alias
- 시작일
- 만료일

안드로이드는 키스토어 파일의 유효기간이 만료되어도, 기존에 기기에 설치한 앱을 계속 사용할 수 있으나,
업데이트는 할 수 없습니다. 같은 앱을 계속 업데이트 하려면, 동일한 키스토어 파일로 앱 설치 파일을
생성해야 합니다.

## 운영 시 APK 파일(안드로이드 앱 설치 파일) 업데이트 시 체크 항목

- 키스토어 파일의 alias 가 동일한지 확인한다.
- APK 파일을 새로 만드는 경우, 기존 설치된 앱 위에 업데이트 설치가 되는지 실기기에서 확인한다.
- 키스토어 파일의 원본과 백업본을 분리 보관한다.
- 키스토어 파일이 유실되면 앱 업데이트가 사실상 불가능하여, 담당자 개인 PC에만 보관하지 않는다.
