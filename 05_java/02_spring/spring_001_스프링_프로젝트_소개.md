# Spring 관련 프로젝트 소개

Spring은 Java 애플리케이션을 만들 때 필요한 여러 기능을 제공하는 생태계입니다.
의존성 주입, 웹 MVC, 데이터 접근, 보안, 배치 처리처럼 애플리케이션에서 반복적으로
필요한 기능을 모듈별로 사용할 수 있습니다.

Spring Framework가 핵심 기반이라면, Spring Boot는 이 기반으로 애플리케이션을
빠르게 시작하고 운영할 수 있도록 기본 설정과 실행 환경을 제공하는 도구입니다.

## Spring Boot

Tomcat, Jetty, Netty 같은 서버를 내장할 수 있어 웹 애플리케이션을 실행하기
편리합니다.

## Spring Data

데이터에 접근하기 위한 기술을 모아둔 프로젝트(JDBC, JPA 등)

데이터베이스에 접근하기 위한 프로젝트입니다.

- JDBC, JPA, Redis, Cassandra, Couchbase, Elasticsearch 등을 지원합니다.

## Spring Cloud

분산 시스템에 필요한 다양한 기술을 모아둔 프로젝트입니다.

클라우드 기반 애플리케이션과 MSA를 개발할 때 활용합니다.

- 분산 시스템에 필요한 기능을 제공합니다.
- 라우팅, 부하 분산, 분산 메시징 등을 지원합니다.

## Spring Security

인증(Authentication)과 인가(Authorization) 관련 기능을 제공하는 프로젝트입니다.

- 인증: 사용자가 본인이 맞는지
- 인가: 특정 자원(페이지 등)에 접근 가능한지

## Spring Batch

대용량 처리를 위해 필요한 기술을 모아둔 프로젝트입니다.

## 스프링부트의 특징

- 자동 설정과 starter 의존성으로 자주 사용하는 구성을 빠르게 준비할 수 있습니다.
- 별도 외장 웹 서버를 설치하지 않고 실행 가능한 애플리케이션을 만들 수 있습니다.
- 설정 부담이 줄어 개발자가 비즈니스 로직과 운영 기능에 집중하기 쉽습니다.

## Spring Boot가 많이 사용되는 이유

Spring Boot는 프로젝트 생성부터 실행, 테스트, 배포까지의 기본 흐름이 단순합니다.
내장 서버와 자동 설정을 사용하면 환경마다 설정하는 작업이 줄어들고, 실행 가능한
JAR 형태로 배포하기도 쉽습니다. Spring 생태계의 데이터 접근, 보안, 모니터링
기능을 필요한 만큼 선택해 확장할 수 있다는 점도 널리 사용되는 이유입니다.
